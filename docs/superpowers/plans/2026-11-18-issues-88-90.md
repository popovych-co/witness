# Issues #88–#90 (rows 240–242) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One decider per stop (#88), unbuilt steps before gates and a park that can be sent back to work (#89), and every ship hold classified so the human's are human stops and the rest are re-checked or re-routed (#90) — witness 0.29.0.

**Architecture:** A settled-since token checked under the state lock keeps the journal right; lean busy locks under `.witness/live/busy/` spare duplicate model calls and ship runs; drive gains its own timers (`retry`, `recheck`) and a held pass. Step routing ignores the first implement gate; a human's revise lifts a park. `witness ship` journals a `ship-outcome` record for the outcome it ends on, and one held predicate (in `flowStep`) feeds `next`, `needsYou` and drive.

**Tech Stack:** TypeScript (ESM, Node ≥ 20), vitest, git and gh CLIs. No new dependency.

**Spec:** `docs/superpowers/specs/2026-11-18-issues-88-90-design.md` (approved 2026-11-18). Each task names the design section it builds; read that section with the task. Rows 240–242 in `DESIGN.md` are already written.

## Global Constraints

- Release 0.29.0 (a new journal entry kind and a newly legal decision); the user runs `pnpm release` — never run it.
- No new committed setting, no `witness migrate`: every bound is a constant or derived from an existing setting (design n3).
- Machine-local files live only under `.witness/live/` (state commits exempt it, `src/gitio.ts:126`); write them without following a link, as `src/live.ts` does.
- Every command a row offers goes through the act renderers (`cliAct`, `runRow`, `shellLine`; row 239). GitHub's and git's text print through `logSafe`.
- Control or bidi characters appear in source only as `\u` escapes; scan every written file with the perl one-liner in memory `raw-escapes-in-written-docs` after writing.
- Parse git output only from git run with `LC_ALL=C` (and `--porcelain` where git has it).
- A new journal kind gets its `ENTRY_PROGRESS` row (`src/progress.ts:10`), or the build fails.
- Skill, command and README text for a behavior lands in the same task as the behavior: `tests/command.test.ts` and `tests/skills.test.ts` pin that text.
- Run tests as `caffeinate -i npx vitest run tests/<file>`; the full suite (`caffeinate -i npx vitest run`, ~12 min, baseline 2733 passed) runs at each slice's end. `npx tsc --noEmit` must stay clean.
- Never `git stash` (the stash stack is shared and holds the user's entries); never `git add -A` (the worktree's `node_modules` is an untracked symlink).
- Probe files from the design passes, reused below as regression tests, live outside the repo in `/Users/home/x/personal/witness/.superpowers/sdd/2026-11-18-issues-88-90/` (`worktree-probes/`, `scratch/pass5-A/`, `scratch/pass5-B/`, `scratch/pass6-D/`, `scratch/pass6-E/`). Copy their setup; invert their final assertions to the fixed behavior.

## Review Focus

- **A lock file a scanner holds or a tampered one** (Windows `EPERM`/`EBUSY`, an `until` that is negative, non-numeric or decades out, a symlink in the busy folder): retried, then `lock-unwritable`, or read as stale — never "busy" forever, never followed. Test added to Task 5.
- **A holder that outlives its bound while still working** (a host sleep mid-settle): a second settler may run; the first one's act must then refuse `settled-since` and the journal must hold one decision. Test added to Task 6.
- **GitHub answering something unexpected in `next`'s check** (a deleted PR, not-found, malformed JSON, a timeout): treated as offline — no record, no crash, the row stands. Test added to Task 17.
- **Two `next` processes running the GitHub check at once**: one `fix` or `re-gate` record, not two (the write re-reads under the state lock and dedups). Test added to Task 17.
- **An amendment that renames or drops a step a `step-close present` names**: progress ignores closes for ids not in the manifest, and the renamed step reads open. Test added to Task 10.
