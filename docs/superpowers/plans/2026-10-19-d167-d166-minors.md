**Goal:** Close the five minors row 166's final review deferred, each with its whole class:

- **Plan gate.** It approves drafts only, through the derivation `decide` already uses.

**Tech Stack:** TypeScript (ESM, NodeNext, `strict` + `noUncheckedIndexedAccess`). Tests are vitest 3.2.7, driving the real CLI in-process against throwaway git repos (`tests/helpers.ts`). Crash tests spawn the built `dist/bin.js` (`tests/protocol/crash.test.ts`). No new dependencies.

**#3 — what a return does when its path is held.**

| Option | Verdict |
|---|---|
| Refuse `path-taken` as a human's decision, naming the holder, unless this same abandon departs the holder | **chosen.** Canon is never written over, and the holder's owner decides |
| Keep the write instead (a `SpecKeep` naming the holder) | rejected. The keep exists for content a plan stands on. No plan stands on a successor whose return failed (the keep rule would already have fired), so canon would describe unbuilt work, and on the effort path the keep is permanent |
| Land the return at another path, e.g. `specs/<id>.md` | rejected. A pin resolves along its spec's path history (`pinCommit(root, rel, sha)`, `src/abandon.ts`), so the plans under a moved spec would lose their pins |
| Hold the path at creation as well (`pathRetired`, at `write` and `adopt`) | **chosen, with the refusal.** It keeps the refusal unreachable from post-167 states, and it closes P8a/P8b. The refusal stays the guarantee for states made before |

**`pathRetired` rule.** A new artifact may not land on a path last witnessed under another id, unless that id's own abandon removed it.
- A superseded spec comes back to that path.
- Any other id left it only by hand. That covers P8a, an in-place id change, which is `rename` done by hand.
- At `adopt` it applies only to a **new** artifact: no stream of its own, and no writing effort. So amendments of any existing doc stay adoptable.

**#4 copy.**
- With human rows present: `help: a human's decision: <rules joined by ' · '> — stop and surface the list; re-running cannot clear it`.
- If some row is not human, append: ` · the other rows are structured for self-repair once it is settled`.
- With no human row: unchanged.

If you drop it, its finding becomes an Open/deferred bullet in Task 7 instead. F4 and F5 are recorded only: each needs design.
